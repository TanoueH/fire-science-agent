## 🧠 Overview
Fire Science Agent is a distributed, containerized multi-agent system designed for intelligent fire detection in tunnel infrastructures.  
It integrates fuzzy logic, machine learning, and web-based knowledge extraction to enable adaptive, explainable, and reproducible risk analysis.

**Core features:**
- Multi-agent orchestration via [CrewAI](https://github.com/joaomdmoura/crewAI)
- Fuzzy + ML hybrid inference engine
- Web scraping for dynamic rule and model updates
- Containerized workflow (Docker Compose)
- Reproducible data pipeline (`sensors.csv → normalized.json → fire_risk.md`)
